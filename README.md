# KPT / EMGS Dashboard

A responsive demo dashboard for university registration, programme approvals and student applications.

Open `index.html` in a browser. No build step or package installation is required.

- University profiles, registration forms and review actions.
- Programme approval drawers with submitted content and review actions.
- Applicant lists, document information and university-specific views.
- Dashboard summaries calculated from the shared demo records.
- Filtered Excel (.xlsx) downloads with selectable columns.
- Settings for sidebar visibility.

Includes 26 fictional universities, 85 programme approval records and 689 fictional applicants. The demo date is 9 October 2026. Email, document and account actions simulate workflows; no backend service is connected.

`Reset Demo` restores the initial records and settings.
